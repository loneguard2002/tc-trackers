Sign-in protection

Failed password sign-ins are counted for each account (the email entered) and each address (the IP address the attempt came from). When either reaches its limit within the window, sign-in is refused until older failures leave the window. Microsoft sign-in is not counted. Failures are kept for 24 hours. Times are UTC.

Report downloads

Each PDF or PNG download starts a browser on the server, which takes far more memory than a page. This limit stops one person from overloading it. The server also draws only one report at a time in each process; that is fixed. Changes apply to the next download and are recorded in Activity.
